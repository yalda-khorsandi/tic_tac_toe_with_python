# Tic Tac Toe with Python

A simple Tic Tac Toe game developed with Python.

## Description

This project is a console-based Tic Tac Toe game where the player competes against the computer.

The player uses `X` and the computer uses `O`.

## Features

- Player vs Computer gameplay
- Input validation
- Win detection
- Draw detection
- Computer move selection
- Colored game output using `termcolor`

## Technologies

- Python
- Termcolor

## Installation

Clone the repository:

```bash
git clone https://github.com/yalda-khorsandi/tic_tac_toe_with_python.git
```

Navigate to the project directory:

```bash
cd tic_tac_toe_with_python
```

Install the required package:

```bash
pip install termcolor
```

## How to Run

Run the following command:

```bash
python tic_tac_toe.py
```

Choose a number from 1 to 9 to place your move on the board.

```text
[1] [2] [3]

[4] [5] [6]

[7] [8] [9]
```
